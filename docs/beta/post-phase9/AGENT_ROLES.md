# Governed Agent Roles

## Provisional status

Phase 9 is locally validated but lacks committed live-node certification. These
Stage 0 role definitions are provisional planning only; they grant no identity,
tool, execution, installation, or activation authority.

Initial roles: Hermes Governor, Atlas, Planner, Builder, Test Engineer, Reviewer,
Release Guardian, Fleet Monitor, Incident Responder, Sigil Analyst, Risk Auditor,
Trace Curator, Dataset Builder, Skill Evolver, Benchmark Evaluator, Regression
Reviewer, and Evolution Guardian.

Builders are confined to assigned worktrees and cannot merge, alter production
secrets, or change trading permissions. Reviewers are independently read-only by
default. Release Guardian validates evidence but cannot bypass human approval.

Internet capabilities are separately allowlisted per role. Public research does
not imply authenticated social access, publishing, GitHub mutation, payments, or
financial execution.
