# Fleet Placement

## Provisional status

Phase 9 is locally validated but lacks committed live-node certification. This
Stage 0 placement is provisional planning only and authorizes no service,
deployment, installation, or runtime activation.

- Titan: governor support, scheduling, queues, embeddings, FinBERT, lightweight
  research and hosted agents within explicit resource budgets.
- Mac: larger reasoning/coding models, Builder, browser-heavy work, candidate
  generation, and large evaluations.
- Prime: independent Reviewer/Release Guardian, monitoring, backup, recovery, and
  infrastructure candidates.

Placement is configurable and bounded by CPU, RAM, disk, storage growth, process
count, service health, privacy, trust, and certification. Agent Reach public-read
pilots may run only on approved profiles/machines; browser-session channels are
not eligible during the initial pilot. Titan must not be overloaded.
