# Sigil Boundary

## Provisional status

Phase 9 is locally validated but lacks committed live-node certification. This
Stage 0 boundary is provisional planning only and authorizes no runtime
integration or financial execution.

Permitted defaults are read-only research, market evidence, source-backed
analysis, paper proposals, and paper-only tests.

Wallets, payments, crypto signing, autonomous spending/publishing, broker
submission, live orders, trading-permission changes, risk-limit changes, and
approval-policy changes are denied. Agent Reach and every other general internet
or worker integration inherit these denials. Future financial execution requires
a separate Sigil certification and explicit human approval.

For this entire provisional program, Sigil remains paper-only and broker
submission remains disabled.
