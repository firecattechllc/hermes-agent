# Sigil Desktop v1.9 — Governed News Workspace

Sigil Desktop v1.9 adds a research-only News workspace to Mission Control.

- Reads the durable governed news evidence projection.
- Displays symbol-specific evidence timelines.
- Displays deterministic advisory summaries.
- Explicitly requests an Alpaca News collection cycle.
- Never accepts credentials in the renderer.
- Never grants execution authority or submits broker orders.
- Collection remains disabled unless `SIGIL_ALPACA_NEWS_ENABLED=true`.
